# Data Inventory
- FRED economic indicators: UNRATE, FEDFUNDS, DGS10, CPIAUCSL, and GDP stored as individual CSV series under `raw/fred/`. Each table holds one observation per date with columns `observation_date` and series value. Coverage spans monthly U.S. unemployment (1948-01-01 to 2026-04-01; 940 rows), monthly CPI-U all items index (1947-01-01 to 2026-03-01; 951 rows), monthly federal funds effective rate (1954-07-01 to 2026-04-01; 862 rows), daily 10-year Treasury yields (1962-01-02 to 2026-05-06; 16,787 rows), and quarterly nominal GDP in billions (1947-01-01 to 2026-01-01; 317 rows). Units follow FRED documentation (percent or index base, GDP billions of chained dollars).
- Treasury Fiscal Data extracts under `raw/treasury/`: `debt_to_penny_full.csv` contains 8,303 daily total public debt balances covering 1993-04-01 through 2026-05-07 with columns for public, intragovernmental, and total debt amounts in USD; `operating_cash_balance.csv` stores 10,000 daily Treasury General Account and related balances for 2014-06-04 through 2026-05-07 in millions; `daily_treasury_yield_curve_2024_2026.csv` aggregates XML feeds into 588 daily par yield observations with maturities from 1 month to 30 years spanning 2024-01-02 through 2026-05-08.
- FHFA all-transactions House Price Index CSVs in `raw/fhfa/`: `hpi_at_state.csv` provides 10,403 quarterly state-level index readings for 51 states/DC covering 1975Q2–2025Q4; `hpi_at_metro.csv` delivers 83,639 quarterly values across 410 metropolitan statistical areas for 1975Q2–2025Q4. Values are index points, no seasonality adjustment metadata embedded.
- Census Building Permits Survey county text files in `raw/census/bps/`: `co2603c.txt` (current month) and `co2603y.txt` (year-to-date) each provide 3,020 county-level records for March 2026 with counts of units, permits, and valuations by structure size. Fields include permit counts by 1-unit, 2-unit, 3-4 unit, and 5+ unit categories with corresponding valuations.
- BLS Local Area Unemployment Statistics API pull at `raw/bls_laus/api/state_unemployment_2019_2026.json`: 4,437 monthly observations covering 51 state/DC series for January 2019 through March 2026, storing employment status values with metadata from the BLS public API (period, year, value, footnotes).
- BLS CPI API response at `raw/bls_api/CUSR0000SA0.json`: monthly national CPI-U all items (seasonally adjusted) values for January 2015 through December 2024 (120 observations) including period metadata and value fields as returned from BLS JSON API.
- ACS 2024 1-year PUMS processed extracts under `intermediate/acs2024_pums/`: `psam_husa.csv` (827,133 housing records with 241 columns) and `psam_pusa.csv` (1,743,751 person records with 286 columns), plus NYC-specific subsets in `intermediate/nyc_pums/` with parquet summaries and thematic indicator CSVs (`employment_and_commuting.csv` 774 rows, `housing.csv` 559 rows, `income_and_poverty.csv` 108 rows, `population_and_demographics.csv` 564 rows) describing estimates, margins of error, and universes for New York City demographic and socioeconomic metrics.
- Census microdata archives stored as provider ZIPs under `raw/census/`: ACS 2024 1-year PUMS (`csv_pus.zip` housing/person files and documentation), CPS January 2026 basic monthly public use file (`jan26pub.zip`), and AHS 2023 national PUF (`AHS_2023_National_PUF_v1.1_CSV.zip`). Each archive preserves original CSV contents, documentation, and layout for downstream extraction.
- FHFA county HPI and HUD datasets currently unresolved: `raw/fhfa/hpi_at_county.csv` and `raw/fhfa/hpi_at_county.error.txt` contain HTML 404 responses (dataset missing); `raw/hud/FY2026_Small_Area_FMRs.xlsx.info.txt` and `raw/hud/US.zip.info.txt` log AWS WAF challenges with no data payload. Marked as blockers until re-downloaded successfully.
- Premium or restricted datasets pending license clearance: `raw/zillow/City_zhvi_uc_sfr_tier_0.33_0.67_sm_sa_month.csv` holds 21,410 location-month Zillow Home Value Index observations (monthly 2000-01–2026-03, USD home values) under license review; `raw/bis/WS_LBS_D_PUB_csv_col.zip` contains BIS locational banking statistics bulk CSVs (quarterly positions through 2025Q4); `raw/oecd/MEI_CLI_USA.json` stores OECD composite leading indicator JSON; `raw/nber/cyclesmain.html` snapshots NBER recession chronology HTML. Redistribution depends on provider terms.
- Blocked BLS direct downloads captured as HTML or header logs under `raw/bls` (`cu.data.1.AllItems`, `la.data.64.County`, `atusresp-2024.zip`, `atusact-2024.zip`) and `raw/bls/cex` (DNS error note). These preserve failure evidence but do not contain usable data tables.
