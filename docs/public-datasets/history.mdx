# Data Inventory
- Library of Congress Civil War Maps JSON metadata extracts (`raw/loc_collections/civil_war_maps_page1.json`, `raw/loc_collections/civil_war_maps_page2.json`) totaling 1,000 map catalog records retrieved 2026-05-13 (`c=500`, `sp=1-2`); one row per digitized map; geography covers U.S. Civil War theaters with frequent locations including Virginia (585 records) and Maryland (111); publication years span 1831-1991; fields include `id`, `title`, `date`, `location`, `subject`, `resources`, `contributor`, `description`, and IIIF manifest URLs; metadata licensed Public Domain (Library of Congress).
- Chronicling America historic newspaper title metadata (`raw/chronicling_america/collection_page_01.json` … `collection_page_10.json`) comprising 1,000 title summaries from ten JSON pages captured 2026-05-13 (`c=100`, `sp=1-10`); one row per newspaper title; United States coverage concentrated in Nebraska (683 titles), Georgia (317), and Virginia (317) with major cities Omaha, Atlanta, and Richmond; issue dates represented range 1909-01-06 through 1928-11-30; fields include `id`, `title`, `number_lccn`, `location_state`, `location_city`, `language`, `publication_frequency`, `subject`, `resources`, and landing URLs; metadata public domain (Library of Congress).
- Europeana World War I API batches (`raw/europeana_api/world_war_i_start001.json`, `raw/europeana_api/world_war_i_start101.json`) storing 200 cultural-heritage item records fetched 2026-05-13 with offsets 1 and 101; one row per object; coverage spans institutions in Germany (119 items), United States (58), United Kingdom (15), Belgium (2), Ireland (2); metadata timestamps and timespans cover 1914-2016; fields include `guid`, `title`, `dataProvider`, `country`, `rights`, `edmTimespanLabel`, `edmPreview`, and `type` (197 IMAGE, 2 TEXT, 1 VIDEO); metadata is CC0 1.0 via Europeana though item-level rights vary.
- Harvard Dataverse history search payloads (`raw/harvard_dataverse/history_search_start000.json`, `raw/harvard_dataverse/history_search_start100.json`) listing 200 dataset-level metadata records pulled 2026-05-13 with offsets 0 and 100; one row per history-tagged dataset; global repository coverage with published years 2007-2026; key fields include `global_id`, `name`, `description`, `publisher`, `subjects` (top tags: Social Sciences 93, Arts and Humanities 56, Computer and Information Science 27, Earth and Environmental Sciences 16, Medicine, Health and Life Sciences 13), `fileCount` (range 0-2,866 files, 194 datasets with files), and dataset landing URLs; metadata CC0 under Dataverse policy.

## Caveats and Deferred Assets
- Digital Public Library of America API request (`raw/dpla_api/civil_war_items_error.json`) returned `invalid_api_key`; no item metadata stored and further access requires a valid DPLA key.
- National Archives Catalog request (`raw/national_archives_catalog/freedmens_bureau_q100.html`) captured an HTML login gate; no JSON metadata exists on disk until credentials are supplied.
- `raw/wikidata_dumps/` directory remains empty because multi-GB CC0 dump transfers are deferred beyond this run; no dump files present.
